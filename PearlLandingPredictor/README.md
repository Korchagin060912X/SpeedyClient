# Pearl Landing Predictor (Fabric, client)

Minecraft: **Java Edition 1.21.8**  
Mod loader: **Fabric**

## Что делает мод
- Находит **все активные** `EnderPearlEntity` вокруг камеры/игрока в радиусе **64 блоков** (включая жемчуги других игроков).
- Каждый кадр предсказывает траекторию полёта (до **100** шагов):
  - текущая скорость (`velocity`)
  - гравитация **0.03**
  - сопротивление воздуха (drag) **0.99**
  - коллизии с блоками через `world.raycast(...)`
- Рендерит:
  - линию траектории с градиентом **зелёный → жёлтый → красный**
  - красный 3D-маркер (квадрат-обводка) в предполагаемой точке удара/приземления

## Зависимости (библиотеки)
База для работы:
- **Fabric Loader**
- **Fabric API**
- **Fabric Loom** (gradle-плагин для сборки)

## Сборка
В корне проекта:

```bash
gradlew build
```

Если Gradle не сможет скачать версии под 1.21.8, обнови значения в `gradle.properties`:
- `loader_version`
- `fabric_api_version`
